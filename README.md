# Movie Search App

A movie search application that helps users discover and browse movies.

![Home Page](/screenshots/home.png)

## Live Demo

## Features

- Search for movies
- View movie details
- Browse similar movies
- Add/remove bookmarks
- Save bookmarks in localStorage
- Error handling

## Technologies

- React
- React Router
- Redux Toolkit
- TanStack React Query
- JavaScript
- CSS
- Vite
- TMDB API
